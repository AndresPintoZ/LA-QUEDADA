# Diseño visual y experiencia de usuario

## Personalidad

La interfaz debe transmitir cercanía, energía, seguridad y facilidad. Debe sentirse juvenil sin ser infantil y servir también a asociaciones y adultos jóvenes.

## Principios de diseño

- Priorizar móvil: el usuario buscará planes mientras está fuera de casa.
- Mostrar primero lo que ocurre cerca y pronto.
- Hacer visible quién organiza y las normas del plan.
- Reducir pasos para apuntarse o crear una quedada.
- No exponer públicamente datos personales ni ubicaciones privadas.

## Navegación principal

Barra inferior en móvil con cinco secciones:

1. **Explorar:** mapa, lista y filtros.
2. **Calendario:** planes por día o semana.
3. **Crear:** crear evento o quedada.
4. **Mis planes:** planes creados, guardados y a los que el usuario se ha apuntado.
5. **Perfil:** datos, intereses, verificación y ajustes.

## Pantallas esenciales

### Explorar

- Cabecera con ciudad, búsqueda y filtros.
- Conmutador entre mapa y lista.
- Tarjetas con imagen opcional, categoría, fecha, distancia, título y plazas.
- Estado claro: plazas disponibles, completo o cancelado.

### Detalle de evento o quedada

- Imagen o color de categoría.
- Título, fecha, hora y lugar.
- Mapa con punto de encuentro.
- Organizador con insignia de “verificado”.
- Descripción, reglas y asistentes.
- Botón principal: “Me apunto”.
- Comentarios y botón de reporte discretamente accesible.

### Crear

- Selector inicial: “Crear una quedada” o “Publicar un evento”.
- Formulario dividido en pasos cortos: información, lugar y reglas.
- Aviso de verificación antes de permitir publicar.
- Vista previa antes de confirmar.

## Sistema visual inicial

| Elemento | Directriz |
|---|---|
| Color principal | Azul intenso o violeta, asociado a confianza y energía. |
| Color de acento | Coral o verde menta para llamadas a la acción. |
| Fondo | Blanco cálido o gris muy claro. |
| Tipografía | Sans serif clara y moderna, con tamaño cómodo en móvil. |
| Iconos | Simples, redondeados y acompañados por texto cuando sea necesario. |
| Tarjetas | Bordes redondeados, sombra leve y jerarquía visual clara. |

## Accesibilidad

- Contraste de color suficiente.
- Tamaño de toque mínimo cómodo en móvil.
- Texto alternativo para imágenes.
- No usar el color como único indicador de estado.
- Formularios con mensajes de error claros.

## Estados importantes

- Vacío: explicar cómo crear el primer plan de una categoría.
- Sin resultados: sugerir ampliar radio, fecha o categoría.
- No verificado: explicar por qué se solicita verificación y qué se conserva.
- Reportado: confirmar recepción sin revelar información sobre otros usuarios.
- Cancelado: informar claramente y sugerir planes similares.
